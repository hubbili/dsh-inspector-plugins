# 执行图

[English](README.md) | 中文

## 摘要

沿输入、提示词、模型请求、响应、工具和继续/结束阅读选中的轮次。查看高亮提示词、图节点、原始事件和精选扩展点地图。复制源码路径，在 WebStorm 阅读另一个 Harness 源码目录。页面读取已加载的 Session 记录，不追踪每个函数或插件回调。

## 使用此包

按仓库的[构建与本地压缩包安装](../../README.zh.md#构建和安装)操作，再选择已有记录的 Session，在“轨迹”后打开“执行图”。默认显示学习导览；节点深链接打开执行图。[内置补丁](cordis.patch.yml)只添加此视图。JSON 检查器可能包含私密提示词、参数和结果，请勿分享真实捕获数据。

## 理解实现

<details>
<summary>实现细节</summary>

[数据投影](src/client/model.ts)读取宿主的 Trajectory 快照。[学习阶段](src/client/learning-stages.ts)结合已加载的生命周期记录，使被拒绝或没有步骤的轮次也可查看。提示词快照展示请求生效输入，不展示各片段贡献者。轮次结束取自 `turn/end`；没有结束记录时保持未知。[扩展点目录](src/client/extension-points.ts)关联相关记录，不推断钩子是否调用。

</details>

## 模型体验

插件不新增模型工具，也不改变模型可见输入。它读取宿主已有的 Session 投影并注册浏览器视图。

## 已知限制与待完善事项

统计只覆盖已加载的历史窗口。源码引用指向另一个 Harness 源码目录，可能随其未稳定 API 改变。相关事件不能证明插件激活或回调耗时。响应时长是步骤开始到响应完成的区间，不是独立网络耗时。模型原始数据不会自动匹配图中的步骤。提示词颜色区分文本结构，不代表贡献该内容的插件。
